# nx-ai-bridge

> **ALPHA - not yet verified on a real NX installation.** The NX side was written without access to NX and is waiting for its first real-machine test. Full README coming in the next commit.

Let any AI tool (Claude, Cursor, Codex, Gemini CLI, ...) drive Siemens NX modelling through MCP or a CLI.

Not a Siemens product. You need your own valid NX licence.
